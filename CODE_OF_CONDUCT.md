# Code of conduct

Rekora is a small project; we keep the rules short.

- Be respectful and assume good intent. Critique code and ideas, not people.
- No harassment, discrimination, personal attacks or sharing others' private information.
- Keep discussions on topic and in English or Spanish.
- Maintainers may edit, hide or remove content and block participants who break these rules.

Report problems privately to the maintainer through GitHub (profile contact or a private security report
marked "conduct"). Reports are handled confidentially.
